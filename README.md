# Hi, I'm Trent

I work on how things happen in practice: where information gets lost, where a process breaks down, and what I can change or build to make it work better. That's been operations and systems work by way of HR, and lately agents and automation, built alongside the people who have to live with the result.

## Completed projects

- **[muse-mcp-bridge](https://github.com/Tjtelenda/muse-mcp-bridge)** — an MCP server (FastMCP, Streamable HTTP) that lets an outside agent platform reach my personal assistant: household tools, Home Assistant state, and a queued ask path for anything that needs judgment.
- **[3ds-homeassistant-local-agent-bridge](https://github.com/Tjtelenda/3ds-homeassistant-local-agent-bridge)** — the server half of a Nintendo 3DS client that shows my house live and controls it: devices, media, PCs, music, and chat with the same assistant.
- **[sheet-music-to-tablature-converter](https://github.com/Tjtelenda/sheet-music-to-tablature-converter)** — turns sheet-music PDFs and MusicXML into aligned bass or guitar tablature. Built so I could learn my parts for a community orchestra.
- **[GuidanceOfGrace](https://github.com/Tjtelenda/GuidanceOfGrace)** — an offline Electron companion for Elden Ring that reads local saves read-only.

## On the bench

- **[MuseChan](https://github.com/Tjtelenda/musechan)** — a fork of Meta's Muse gadget SDK that puts my Muse on a StackChan desk robot: face, head servos, live reactions, outfit updates over the air. In daily use, still evolving.
- **[Local-agent-bridge](https://github.com/Tjtelenda/Local-agent-bridge)** — a retired prototype (WebSocket bridge + FastAPI relay between a cloud agent and local systems). Kept public under MIT for reference; the two bridge projects above are what replaced it.
